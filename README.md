# Sun & Moon Logic Puzzle

A mobile-first, dependency-free HTML/CSS/JavaScript logic game inspired by the familiar Sun/Moon binary puzzle format.

## Features
- Infinite deterministic 6×6 levels with unique-solution verification
- Sun / Moon cell cycling
- `=` same and `×` opposite relationship clues
- Equal Sun/Moon row and column rules
- No three identical pieces consecutively
- Autosave / resume via localStorage
- Automatic next level after completion
- Undo, hints, restart, timer, streaks, level picker and stats
- Sound, haptic feedback and high-contrast option
- Responsive mobile/desktop UI
- Offline-ready PWA service worker
- No frameworks or third-party dependencies

## Run locally
Open `index.html` directly, or serve the folder using any static web server.

## Hosting
This is a fully static site and works on GitHub Pages, Cloudflare Pages, Netlify, Vercel or any standard static host.
